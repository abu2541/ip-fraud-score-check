## “最稳”到底是什么？四个能动手验证的标准

平台风控判断你是谁，主要看两块：网络和设备。所谓“稳”，就是把这两块做到能通过检查的样子。具体拆开是四个条件。

**IP 要独享。** 共享 IP 池里，一条 IP 上登录过多少别人的账号你不知道，别人账号出事，你会被连坐。用公共 VPN 养的号权重低、容易被封，原因就在这——一堆账号挤在同一个出口上，平台的关联判定一抓一个准。

**IP 类型要干净。** 按质量排：手机 IP > 住宅 IP > 服务器（机房）IP。手机 IP 来自真实用户和基站，住宅 IP 来自家庭宽带，机房 IP 来自企业专线和云服务器，号段连号，最容易触发风控。日常运营住宅 IP 已经够用，想再稳一点就往静态住宅靠。

**欺诈值要低。** 在 scamalytics.com 输入 IP 查分，分数越低越好。注册 Instagram、Facebook 这类高风控平台，结果最好控制在黄色或绿色。顺带说一句，别迷信绿色：国内家宽很多测出来也是黄色，但那其实是非常好的住宅 IP。

**环境和 IP 要对得上。** 时区、语言、定位都切到 IP 所在国家；浏览器打开 whoer.net，伪装度测到 100 才算过关。用苹果设备的多做两步：关闭 iPhone 分析、关闭 Apple 个性化广告。IP 在美国、手机语言是中文，这种组合一眼假。

## 下单之前，先把两个网站用明白

第一步，拿到线路的 IP。服务商后台一般会提供；没给的话，连上节点后打开 ipinfo.io，右侧默认显示当前网络的 IP 地址。

一个提醒：不同查询网站的数据库不一样，同一个 IP 在不同站测出不同国家很正常，这些结果只做相对参考，别当绝对标准。

## 比选错套餐更伤账号的四个坑

海外网络环境搭建这件事，失败案例大半出在下面四点。

**假静态住宅 IP。** 市面上大量号称“静态住宅”的其实是机房 IP 冒充，真静态住宅需要向当地运营商单独申请，成本高，很少有服务商真给。拿到手第一件事：ipinfo.io 查类型，显示 hosting 的直接找售后。

**定位和 IP 打架。** IP 在美国、定位定在首尔，这种组合容易直接触发平台的封禁机制。模拟定位的城市要跟线路 IP 所在城市对上，查 IP 归属地用 en.ipip.net 就行。

**一条线路挂太多号。** 就算是独享 IP，同 IP 上塞的账号越多，互相连坐的概率越大。一条线路同时只该有一个环境在用，多账号错开时间复用都算将就。

**以为环境做好就万无一失。** 不同平台风控强度不一样，IP 和设备环境只是基本盘，注册邮箱的质量、养号时的操作习惯同样算进权重里。能做的是把可控项全部做满，剩下的交给时间和内容。
